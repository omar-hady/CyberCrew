# Start Your Cybersecurity Learning Journey

CyberCrew Learning Paths are designed to help learners move from basic knowledge to practical cybersecurity skills through structured learning stages.

## Choose Your Direction

Explore the available learning journeys:

* **Cybersecurity Foundations:** Build the essential knowledge in Linux, networking, and computing.
* **Core Cybersecurity Skills:** Develop the technical skills needed before specializing.
* **Red Team:** Explore offensive security concepts and penetration testing methodology.
* **Blue Team:** Learn security monitoring, detection, and incident response.
* **CTF:** Practice problem-solving through hands-on cybersecurity challenges.

## Learn Step by Step

Each learning path is organized into stages. Start with the essential foundations, study the recommended resources, and progress toward more advanced topics.

## Ready to Begin?

Visit the Learning Paths section and choose the journey that matches your current level and goals.

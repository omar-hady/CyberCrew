# Linux Command Line Fundamentals

## Overview

Linux is one of the most important operating systems in the cybersecurity field. Security professionals use Linux daily for system administration, network troubleshooting, scripting, penetration testing, and security monitoring.

This learning resource introduces beginners to the Linux command line and helps them build the practical skills needed before moving into specialized cybersecurity topics.

## Learning Objectives

By the end of this resource, learners should be able to:

* Understand what Linux is and why it matters in cybersecurity.
* Navigate the Linux filesystem using terminal commands.
* Create, copy, move, and remove files and directories.
* Read and manage basic file permissions.
* Understand users, groups, and basic system information.
* Use command-line help and documentation.

## 1. Introduction to Linux

Linux is an open-source operating system widely used in servers, cloud infrastructure, networking, and cybersecurity.

Popular Linux distributions include:

* Ubuntu
* Debian
* Fedora
* Kali Linux
* Arch Linux

**Important:** Kali Linux is designed for security testing and is not a replacement for learning general Linux fundamentals.

## 3. Filesystem Navigation

Linux uses a hierarchical filesystem that starts at the root directory `/`.

Important directories include:

* `/home` — User home directories.
* `/etc` — System configuration files.
* `/var` — Variable data such as logs.
* `/tmp` — Temporary files.
* `/root` — The root user's home directory.

## 4. Users and Permissions

Linux uses permissions to control who can read, write, or execute files.

The three basic permission types are:

* `r` — Read
* `w` — Write
* `x` — Execute

Useful commands:

* `chmod` — Change file permissions.
* `chown` — Change file ownership.
* `id` — Display user and group information.

## 5. Practical Exercises

Try the following tasks in a Linux terminal:

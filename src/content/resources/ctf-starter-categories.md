Treat CTFs as deliberate practice, not only scoreboard chasing. Rotate categories so weak areas get reps while strengths stay sharp.

## Category rotation

| Category | Early focus | Common blockers |
| --- | --- | --- |
| Web | Requests, cookies, XSS/SQLi basics | Blind trust of client-side checks |
| Crypto | Encoding vs encryption, classic ciphers | Skipping plaintext assumptions |
| Forensics | File carving, metadata, timelines | Tool-hopping without a hypothesis |
| Reverse | Strings, control flow, simple unpacking | Jumping to decompiler before basics |
| Pwn | Memory layout intuition, simple overflows | Skipping crash reproduction notes |

## Practice loop

1. Pick one category for a short timed block.
2. Attempt the challenge; capture what blocked you in one paragraph.
3. Find or write a resource that closes that gap (library note, official docs, writeup).
4. Retry a similar challenge within a week.

## After the session

Share short takeaways with the crew when allowed by event rules. Link useful materials into the library instead of leaving knowledge only in private chat history.
